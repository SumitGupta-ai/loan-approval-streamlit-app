# 🏦 Loan Approval Prediction Web Application
---
## 📌 Project Overview

- End-to-end Machine Learning web application
- 
- Predicts whether a loan will be Approved or Rejected

- Built using a Random Forest Classifier

- Deployed as an interactive web app on Streamlit Cloud

- **This project demonstrates a complete ML pipeline —
from data preprocessing → model training → evaluation → deployment.**
---

## 🧠 Machine Learning Details

- Problem Type: Binary Classification

- Target Variable: Loan Approval Status

- Algorithm Used: Random Forest Classifier

## 📊 Model Performance

- ✅ Accuracy: ~91%

- ✅ ROC-AUC Score: ~96%

- ✅ Evaluation Metrics Used:

- Accuracy Score

- ROC-AUC

- Confusion Matrix (during training)
